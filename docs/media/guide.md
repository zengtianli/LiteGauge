# 安装与日常使用

1. 从 [正式版本](https://github.com/zengtianli/LiteGauge/releases/latest) 下载 ZIP 或 DMG；当前支持 Apple Silicon、macOS 14 及以上。
2. ZIP 解压后，或打开 DMG 后，把 LiteGauge.app 拖入“应用程序”。
3. 打开 LiteGauge，在右上角菜单栏看到 CPU 和两根竖条即已运行。首次 CPU 读数等待约 1 秒。
4. 点击指示器展开详情；菜单中的“立即刷新”支持 ⌘R，“退出轻仪”支持 ⌘Q。

发行包经过 Developer ID 签名与 Apple 公证，不需要辅助功能、屏幕录制或完全磁盘访问权限。

完整报错、更新、卸载说明见 [官网教程](https://litegauge.tianli.cyou/#install) 与 [README](../../README.md)。本目录截图是同源 AppKit 界面的固定示例值渲染；视频使用实时采样数据进行离屏演示，没有录制 Finder 安装或实际菜单点击。
